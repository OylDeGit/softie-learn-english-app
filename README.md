# 雅思泡泡 · General Training

面向目标 6–7 分的雅思 G 类备考者：每天约 30 分钟，把词汇练到能提取、能运用。免登录、无后端，保留 3000 词和原有进度。

基于 [yuanyang749/softie-learn-english-app](https://github.com/yuanyang749/softie-learn-english-app) 的个人非官方改编，保留 Softie 角色、音效、原版演出与作者署名。角色使用约束见 [LICENSE-SOFTIE](LICENSE-SOFTIE)，词典来源许可见 [LICENSE-ECDICT](LICENSE-ECDICT)。与 IELTS 官方无关联，不提供雅思估分。

## 每日四步

| 阶段 | 建议时间 | 安排 |
|---|---:|---|
| 到期复习 | 8 分钟 | 跨玩法收集已到期题，最多 16 题；没有到期题时自动接续 |
| 新词学习 | 8 分钟 | 默认最多 10 个核心新词，优先已校核的场景词；额度按词汇合并计数 |
| 提取训练 | 6 分钟 | 对已接触词安排缺少的识义、听写或搭配训练，最多 12 题 |
| 场景应用 | 8 分钟 | 按日轮换阅读、书信片段和观点段落 |

时长只用于安排节奏，不强制截断。自动计划遵守复习到期时间；错题本可手动立即重练。到期积压超过 20 题时新词上限暂降到 5 个，超过 40 题先复习。每日目标支持 5/10/15/20/30 词与三档难度；已开始计划的配置固定，完成后调整用于下一次计划。

已完成题、当前阶段和答题断点都会保存。刷新后点“继续今天的学习”，可恢复解析页或尚未完成的题；错答和提示记录保留。新一天从新的计划开始，已作答记录不丢弃。

## 训练与内容

- **识义、补字母、完整听写各 3000 词；语境、搭配各 500 词**，共 10000 道派生词汇题。全部词的 ID 和原层级保留，基础、核心、进阶各 1000 词。
- **500 个场景词**：校核主释义、词性与例句关系；场景页优先展示相应词义，已收录的其他词义可展开。搭配练习支持提取目标词或介词。
- **词族与改写**：展示词族、适用语境和句型提醒，另有 20 道固定答案微练习；不将近义词机械视为可互换。
- **G 类阅读 8 篇 / 28 题**：生活、职场短文及两篇约 385/399 词的一般兴趣文章。默认英文题干，可打开中文题意辅助，答后提供解释和原文依据。
- **书信 12 场景 / 观点表达 6 主题**：支持草稿、内容自查和参考表达。自由写作仅检查篇幅与自查完成情况，不自动判断语言质量或生成分数。
- **五种自由练习与限时挑战**：学习默认不限时。挑战中基础 40 秒、核心 35 秒、进阶 30 秒；完整听写 60 秒。朗读、弹窗和后台期间不计倒计时。
- **3000 词可搜索词表**：中英文与搭配查询、按话题/难度筛选，每页 20 词，显示三个技能维度的状态。

## 接触与稳定程度

识义、听写、搭配分别记录。“练过一次”属于已接触，不等于掌握。每个维度至少两次跨日、无提示独立答对，才标记该维度稳定；提前重复答对不新增稳定证据，也不延长原复习日程。使用提示、重试或跳过会保留为需要巩固。

旧的各玩法存档及日程保留，迁移时只标记已接触，不伪造跨日证据。2500 个没有搭配题的词明确显示搭配维度尚未覆盖。首页展示近 7 天首答和跨日到期复习的实际分子/分母；暂无样本时不生成百分比。以上是产品学习规则，不对应雅思分数。

## 手机与保存

底部“今日 / 词表 / 错题 / 我的”导航。每日训练减少强动效，签到和奖杯由用户主动打开；自由演示与原版演出保留。弹窗固定在视口内，支持滚动、安全区和软键盘可视空间调整。

记录保存在当前浏览器，不会自动跨设备同步。页面显示保存状态，失败时在“我的”中重试，或导出包含内存中未保存记录的备份。每 7 天温和提醒备份；下载后请确认文件确已保存。

JSON 备份包含旧玩法记录、技能证据、每日断点、草稿、自查、阅读答案和微练习。支持选择文件或粘贴文本，检查预览后合并；重复导入不重复累计，保留本机设置。清理浏览器数据或换设备前请先备份。

## 本地运行与验证

零 npm 依赖，无构建步骤。需要 Node.js 20+ 与 Python 3。

```bash
npm run dev
npm test
```

打开 `http://127.0.0.1:8016`，不要直接双击 HTML。GitHub Pages 从 `master` 分支根目录发布，保留 `.nojekyll`。

核心模块：`js/skills.js` 记录维度与跨日证据；`js/curriculum.js` 安排四步与断点；`js/study-tools.js` 提供导航、场景和备份界面。现有 `softie-ielts-gt:` 存档继续使用，新增技能键为 `skills:v2`、断点键为 `daily-session:v1`；旧启蒙/成语记录不受影响。
